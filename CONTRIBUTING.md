# Contributing

Found a bug? A missing intent? A shop type this kit should support?

1. Check the bug is real: run `python3 tests.py` first and describe what you did.
2. Keep the kit offline-first: the rules engine must keep working with no key and no internet.
3. Never add a real phone number, a real API key, or real shop data to the repo. Demo data only.
4. One change per pull request. Add a test in `tests.py` for any new behaviour.
5. Suggestions in Roman Urdu or English are both welcome.
